GTA V 视觉感知与辅助驾驶实验

本仓库包含面向 GTA V 游戏画面的 Python 视觉处理代码：屏幕捕获、目标检测、车道线检测与多目标跟踪。 此页面仅展示已验证的演示素材与代码目录结构，不对自动驾驶等级、准确率或完成度作任何承诺。

🎯 目标检测

源码引用 YOLO（Darknet 与 PyTorch 两套实现），用于检测画面中的车辆等目标。

  • MutilCarDection.py
  • MutilCarDection_by_pytorch_yolo2.py
  • yolo-coco/

🛣️ 车道线检测

集成 Ultra-Fast-Lane-Detection 风格的 PyTorch 模型（fastlanedetection/）。

  • visualization_by_pytorch.py
  • visualization.py

📡 多目标跟踪

SORT 算法配合卡尔曼滤波（kalman.py），用于关联检测框。

  • gtav.py 主循环
  • util/control.py Windows 键盘模拟

处理管线（据源码推断）

基于 gtav.py 中 autopilot() 函数的调用顺序整理，仅为结构说明。

屏幕捕获 ImageGrab / win32
→
YOLO 检测 yolo_predict
→
车道线检测 lane_predict
→
SORT 跟踪 Kalman + IoU
→
可视化输出 cv2.imshow

运行环境

代码依赖 Windows API（win32api、win32gui）与 CUDA 后端，面向 Windows 平台开发。

有限状态机目录

有限状态机/ 含车速数据采集、键盘时间检测与神经网络实验脚本，与主视觉管线为独立模块。

仓库结构（摘要）

主要模块与职责，不含 有限状态机/速度仿真控制模拟数据处理/data/ 下的大量训练用小图。

GTA-V-Autopilot/
├── gtav.py                          # 主入口：屏幕捕获 + autopilot 循环
├── MutilCarDection.py               # YOLO (Darknet) 车辆检测
├── MutilCarDection_by_pytorch_yolo2.py# YOLO (PyTorch) 车辆检测
├── visualization_by_pytorch.py      # 车道线检测 + 可视化
├── kalman.py                        # SORT 跟踪 + 卡尔曼滤波
├── fastlanedetection/               # 车道线模型
├── yolo-coco/                       # YOLO 配置与权重路径
├── util/                            # Windows 键盘控制
├── build_utils/                     # 工具与数据集辅助
├── 有限状态机/                       # 车速数据、键盘检测、NN 实验
├── demo.jpg                         # 静态演示截图
├── video/
│   ├── project_video.mp4
│   └── project_video2.mp4
└── wtx.mp4                          # 视觉管线输出录制
